# GA Learning Magic Touch

AI-powered makeup recommendation app with face scanning technology.

Personalized makeup styles for beginners (16-25 years old).
Available in Spanish & English.

## Features

- Face scanning (3 angles)
- AI recommendations
- 10 makeup styles
- Favorites system
- Responsive design

## Tech Stack

- React 18
- Supabase
- Vite
- Zustand

## Deploy

Deployed on Vercel.
